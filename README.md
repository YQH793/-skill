# skill
## 📦 下载与安装

### 1. 下载最新版本
请前往 [Releases](你的GitHub_Releases链接) 页面，下载最新版本的 `pigi-high-score-playbook.zip`。

### 2. 安装步骤
1. 解压下载的 zip 文件。
2. 将解压后的文件夹放到你的 DSH 插件目录下（例如 `plugins/` 目录）。
3. 重启你的 DSH 环境。

### 3. 开始使用
在对话框中输入以下指令调用该 skill：
`/use pigai-high-score-playbook`
