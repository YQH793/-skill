## 怎么用

**方式一（推荐）**：把 `SKILL.md` 的内容作为上下文提供给 AI，然后说：
> "按这份攻略，帮我针对这个题目写一篇批改网高分作文：<题目原文>"

**方式二**：直接问我"批改网怎么得高分"，我会先走 `SKILL.md` 的 **§0 三步环境诊断**（题目／快速体验版还是老师作业／能提交几次），再决定用哪套策略。

## 如果只做三件事

批改网数的是**统计特征**，不是文章质量。按实测收益排序：

1. **把题干关键词原词复现进正文** —— 「内容相关分」实测就是与题干的**单词短语重复率**（把 `AI` 写成缩写会大幅掉分）。
2. **把简单句大量改造成 `that/which` 从句 + 每段加连接词** —— 提"句子分"和"篇章结构分"；系统**只数从句密度，不挑类型**。
3. **消灭所有红色错误标记，但别盲从"建议"** —— 红色标记直接扣分，而盲从建议实测会**越改越低**（有人 90 → 70）。

**反面清单**：换"高级词"（有对照实验显示完全不涨分）、拆段落（几乎不影响总分）、钻研高级从句（系统不敏感）。

## 三个最该记住的结论

1. **批改网分数 = 你的作文与它语料库之间的距离**（官方原文）。所以"高级但常见"胜过"高级但生僻"，莎士比亚式表达会**掉分**。
2. **环境决定策略**：快速体验版可用"真人模仿风"冲高分；学校/老师作业版要用"传统学术风"才稳。同一篇作文不同班级能差 20 分。
3. **母语者原文实测也只有 85.5 分**（媒体复现）。所以"上不了 90"是普遍现象，别把批改网分数等同于写作水平。
